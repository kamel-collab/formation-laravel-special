## Exercices et guides

Le dossier `TD/` contient l’exercice HTML/CSS du jour 1 et les guides de travaux pratiques des projets interface et Laravel. Le guide k6 contient les explications détaillées et le guide de sécurité conserve les captures Postman.

Les PDF issus des diaporamas reproduisent les diapositives sous forme d’images : leur texte ne peut pas être sélectionné. Le texte des guides de TD reste sélectionnable. Pour modifier un support de cours, utilisez son fichier source PowerPoint ou Word.
